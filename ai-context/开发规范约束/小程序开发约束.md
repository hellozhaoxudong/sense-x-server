## 一、总览
本文档用于约束 AI 编码过程，确保 AI 生成的代码符合项目标准。

## 二、小程序代码结构
- 主目录: sense-app
- 公共组件: sense-app/src/components
- 静态资源: sense-app/src/static
- 主应用页面: sense-app/src/pages
- 租房子应用分包页面: sense-app/src/moduleRent/pages
- 租房子应用分包API: sense-app/src/moduleRent/api
- 页面路由配置: sense-app/src/app.config.js

## 三、页面文件及命名规范
- 如果是子应用，则应写在相应的分包目录下，路径为：sense-app/src/module+应用名/pages
- 如果为简单应用，没有模块的概念，则页面存储路径为：pages/功能名/功能名.vue
- 如果为简单应用，有模块的概念，则页面存储路径为：pages/模块名/功能名/功能名.vue
- 向app.config.js注册路由时，应写到具体分包下
- 功能列表页vue命名：功能名.vue
- 编辑页vue命名：功能名Edit.vue
- 详情页vue命名：功能名Detail.vue

## 四、API请求规范
- 如果是主包的请求，则应将所有请求归集到：sense-app/src/api/模块名/功能名.js
- 如果是分包的请求，则应将所有请求归集到：sense-app/src/module应用名/api/模块名/功能名.js
- 请求js中，应使用封装好的request.js发送请求
- 查询方法命名: query功能名(params)
- 查询详情方法命名: query功能名Detail(params)
- 提交方法命名: submit功能名(data)
- 删除方法命名: delete功能名(params)

## 五、页面内约束
- 常见情况下，页面加载时查询数据，应放在一个function initData()中，onMounted中调用这个方法
- 删除按钮方法命名：onDelete功能名()，应使用Taro.showModal进行二次确认
- 编辑页提交按钮方法命名：onSubmit()
- 发送请求前，应使用 Taro.showLoading({ mask: true }) 锁定页面，finally中关闭加载动画
- 严禁使用computed进行数据转换
- 从url中获取参数，应使用 const router = useRouter(); router.params.参数名;

## 六、Form表单约束
- form必须设置：ref、:model-value
- form-item必须设置：label、prop、required、rules
- rules禁止设置message，仅设置required即可
- form-item中的input，必须设置max-length，防止用户输入过长
- onSubmit()提交时，必须验证表单是否填写完整：formRef.value?.validate()

## 八、编码示例
- 接口请求
```js
// 查询房间列表
export function queryRooms(){
    return request({
        url: '/api/rent/rentRoom/query',
        method: 'GET'
    })
}

// 查询房间详情
export function queryRoomDetail(params){
    return request({
        url: '/api/rent/rentRoom/detail',
        method: 'GET',
        params: params
    })
}

// 提交房间信息
export function submitRoom(data){
    return request({
        url: '/api/rent/rentRoom/submit',
        method: 'POST',
        data
    })
}
```

- 表单编辑页面
```vue
<template>
  <CommonPage>
    <LightTitle>编辑房间信息</LightTitle>

    <nut-form ref="formRef" :model-value="formData">
      <nut-form-item label="小区/村" prop="areaName" required :rules="[{ required: true }]">
        <nut-input v-model="formData.areaName" placeholder="请输入小区/村" type="text" max-length="20"/>
      </nut-form-item>
      <nut-form-item label="楼号" prop="buildNo" required :rules="[{ required: true }]">
        <nut-input v-model="formData.buildNo" placeholder="请输入楼号" type="text" max-length="10"/>
      </nut-form-item>
      <nut-form-item label="楼层" prop="floorNo" required :rules="[{ required: true }]">
        <nut-input v-model="formData.floorNo" placeholder="请输入楼层" type="text" max-length="5"/>
      </nut-form-item>
      <nut-form-item label="房间号" prop="roomNo" required :rules="[{ required: true }]">
        <nut-input v-model="formData.roomNo" placeholder="请输入房间号" type="text" max-length="8"/>
      </nut-form-item>
      <nut-form-item label="标准租金" prop="initPrice" required :rules="[{ required: true }]">
        <nut-input v-model="formData.initPrice" placeholder="请输入标准租金" type="number" max-length="10"/>
      </nut-form-item>
    </nut-form>

    <nut-button type="info" block @click="onSubmit">提交</nut-button>
  </CommonPage>
</template>


<script setup>
// 路由
const router = useRouter();

// 表单数据
const formRef = ref(null);
const formData = ref({
  areaName: '',
  buildNo: '',
  floorNo: '',
  roomNo: '',
  initPrice: '',
})

const roomId = router.params?.id

onMounted(() => {
  if (roomId){
    initDetail(roomId);
  }
})

// 初始化详情
function initDetail(roomId){
  Taro.showLoading({ mask: true });
  queryRoomDetail({id: roomId}).then(res => {
    formData.value = res.data || {};
  }).finally(()=>{
    Taro.hideLoading();
  })
}

// 提交
function onSubmit() {
  // 表单验证
  formRef.value?.validate().then(({ valid }) => {
    if (!valid){
      // 提示必填项
      Taro.showToast({ title: '请将必填项填写完整', icon: 'error', duration: 1500 });
      return;
    }

    // 保存至后端
    submitRoom(formData.value).then(() => {
      Taro.showToast({ title: '保存成功', icon: 'success', duration: 1500 });
      // 跳转回列表页
      Taro.navigateTo({ url: `/moduleRent/pages/room/RentRoom` });
    })
  });
}
</script>
```
