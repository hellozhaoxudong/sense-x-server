## 一、总览
本文档用于约束产品前端 AI 编码过程，确保 AI 生成的代码符合项目标准。

#### 前端代码结构
服务端代码放置在sense-ui工程下，是一个vue3+arco-design项目：
- sense-ui/src/views/base：基础模块，主要是基础管理功能。
- sense-ui/src/views/core：核心模块，主要是用户体系、核心登录功能。
- sense-ui/src/views/hir：智能审核平台，智能审核平台相关前端代码全部放在这个模块下
- sense-ui/src/views/eed：全程管理平台，全程管理平台相关前端代码全部放在这个模块下

## 二、目录与命名约束

### 2.1 目录结构
- sense-ui/src/api: API接口，按应用分子目录
- sense-ui/src/views: 页面文件，按应用分子目录
- sense-ui/src/core/component: 通用组件，所有页面均应使用这些通用组件
- sense-ui/src/router: 路由文件，应用分子文件，通过index.js统一引入
- sense-ui/src/utils: 工具函数

### 2.2 页面文件及命名规范
- 页面应存放在views/应用名/模块名目录下
- 功能列表页vue命名：功能名.vue
- 编辑页vue命名：功能名Edit.vue
- 详情页vue命名：功能名Detail.vue

### 2.3 API请求规范
- 应将所有请求归集到：sense-ui/src/api/应用名/模块名/功能名.js
- 请求js中，应使用封装好的request.js发送请求
- 查询方法命名: query功能名(params)
- 查询详情方法命名: query功能名Detail(params)
- 提交方法命名: submit功能名(data)
- 删除方法命名: delete功能名(params)

### 2.4 页面内约束
- 常见情况下，页面加载时查询数据，应放在一个function initData()中，onMounted中调用这个方法
- 删除按钮方法命名：onDelete功能名()，应使用 Modal.info({ title: '操作确认', content: '确定要删除吗？'}) 进行二次确认
- 编辑页提交按钮方法命名：onSubmit()
- 发送请求前，应使用 loading 锁定页面，finally中关闭加载动画
- 严禁使用computed进行数据转换

## 2.5 Form表单约束
- 要直接使用ArcoDesign的Form组件;
- 要配置auto-label-width，让组件自动设置布局，不要手动设置a-form-item的label-col、wrapper-col宽度;
- form-item中的input，必须设置max-length，防止用户输入过长，禁止设置placeholder
- 表单项为必须输入时，要配置: rules="[{ required:true, message:'必选项' }]"，注意message统一写为'必选项'，不要写具体业务字段
- 点击保存、提交按钮时，要使用formRef.value.validate检查表单项是否填写完整;

### 2.6 按钮约束
按钮的样式、图标必须遵守以下要求：
- 新建按钮：<a-button type="primary"><template #icon><icon-plus /></template>新建</a-button>
- 删除按钮：<a-button type="primary" status="danger"><template #icon><icon-delete /></template>删除</a-button>
- 导入按钮：<a-button type="outline"><template #icon><icon-upload /></template>导入</a-button>
- 导出按钮：<a-button type="outline"><template #icon><icon-download /></template>导出</a-button>
- 表格行内文字按钮：<TextBtns><div>编辑</div> <div>分配</div></TextBtns>

## 四、代码示例
#### 请求
```js
import HttpRequest from "../../../utils/request.js";

export function queryUser(params){
  return HttpRequest({
    url: '/api/core/user/query',
    method: 'get',
    params
  })
}

export function submitUser(data){
  return HttpRequest({
    url: '/api/core/user/submit',
    method: 'post',
    data
  })
}

export function deleteUser(data){
  return HttpRequest({
    url: '/api/core/user/delete',
    method: 'post',
    data
  })
}
```

#### 表格页面
```vue
<template>
  <CommonLightTable
          title="用户管理"
          :data="table.data"
          :total="table.total"
          @search="initData"
          :loading="loading"
          @selectRowIds="(ids)=>selectRowIds = ids"
          :page="table.page"
          :page-size="table.pageSize"
          @pageChange="(p, s)=>{ table.page = p; table.pageSize = s; initData(); }"
  >
    <!--查询区域-->
    <template #search>
      <SearchItem label="登录名称"><a-input v-model="table.tableFilter.username" size="small"/></SearchItem>
      <SearchItem label="用户姓名"><a-input v-model="table.tableFilter.name" size="small"/></SearchItem>
      <SearchItem label="邮箱"><a-input v-model="table.tableFilter.email" size="small"/></SearchItem>
      <SearchItem label="手机号"><a-input v-model="table.tableFilter.phone" size="small"/></SearchItem>
    </template>

    <!--表格操作-->
    <template #operation>
      <a-button type="primary" @click="modalShow.edit=true">新建</a-button>
      <a-button status="danger" @click="onDelete()">删除</a-button>
    </template>

    <!--字段信息-->
    <template #columns>
      <a-table-column title="登录名" data-index="username" :width="140" ellipsis tooltip />
      <a-table-column title="用户姓名" data-index="name" :width="160" ellipsis tooltip />
      <a-table-column title="性别" data-index="sex" :width="70" ellipsis tooltip>
        <template #cell="{ record }">
          <span v-if="record.sex==='M'">男</span>
          <span v-else-if="record.sex==='W'">女</span>
          <span v-else>未知</span>
        </template>
      </a-table-column>
      <a-table-column title="手机号" data-index="phone" :width="160" ellipsis tooltip />
      <a-table-column title="邮箱" data-index="email" :width="200" ellipsis tooltip />
      <a-table-column title="角色" data-index="roleNames" ellipsis tooltip />
      <a-table-column title="锁定" data-index="locked" :width="90" ellipsis tooltip>
        <template #cell="{ record }">
          <a-tag v-if="record.locked==='Y'" color="danger">red</a-tag>
          <a-tag v-else>未锁定</a-tag>
        </template>
      </a-table-column>
      <a-table-column title="启用" data-index="enabled" :width="90" ellipsis tooltip>
        <template #cell="{ record }">
          <a-tag v-if="record.enabled==='Y'" color="arcoblue">启用中</a-tag>
          <a-tag v-else>未启用</a-tag>
        </template>
      </a-table-column>
      <a-table-column title="操作" data-index="operation" fixed="right" :width="80" ellipsis tooltip>
        <template #cell="{ record }">
          <a @click="onEdit(record)">编辑</a>
        </template>
      </a-table-column>
    </template>
  </CommonLightTable>

  <!--新建/编辑-->
  <EditUser v-if="modalShow.edit" :edit-data="currentEditRow" @close="modalShow.edit = false; currentEditRow={}; initData();" />
</template>

<script setup>
  import {onMounted, ref} from "vue";
  import {deleteUser, queryUser} from "../../../api/core/user/user.js";
  import {Message} from "@arco-design/web-vue";

  const loading = ref(false);

  // 表格数据
  const table = ref({
    data: [], // 数据
    total: 0, // 总数
    page: 1,  // 显示第几页
    pageSize: 50, // 每页显示多少条
    tableFilter: { username: '', name: '', email: '', phone: '' } // 表格筛选
  });
  // 选中数据ID
  const selectRowIds = ref([]);

  // 编辑中的一行
  const currentEditRow = ref({});

  // 弹窗
  const modalShow = ref({
    edit: false
  })

  onMounted(()=>{
    initData();
  })

  // 初始化查询
  function initData(){
    const params = {
      page: table.value.page,
      pageSize: table.value.pageSize,
      ...table.value.tableFilter
    }

    loading.value = true;
    queryUser(params).then(res=>{
      table.value.data = res.data;
      table.value.total = res.headers['x-total-count'] ? Number(res.headers['x-total-count']) : 0;
    }).finally(()=>{
      loading.value = false;
    })
  }

  // 编辑
  function onEdit(row){
    currentEditRow.value = row;
    modalShow.value.edit = true;
  }

  // 删除
  function onDelete(){
    loading.value = true;
    deleteUser(selectRowIds).then(res=>{
      Message.success('删除成功');
      initData();
    })
  }
</script>
```

#### 编辑页面
```vue
<template>
  <CommonModal title="用户信息" :width="'600px'" @ok="submit" @close="emit('close')">
    <a-form ref="formRef" :model="formData" autocomplete="off" auto-label-width>
      <a-form-item label="登录名" field="username" :rules="[{ required: true, message: '必填项' }]">
        <a-input v-model="formData.username" autocomplete="new-password"/>
      </a-form-item>
      <a-form-item label="密码" field="password" :rules="[{ required: true, message: '必填项' }]">
        <a-input-password v-model="formData.password" autocomplete="new-password"/>
      </a-form-item>
      <a-form-item label="手机号" field="phone" :rules="[{ required: true, message: '必填项' }]">
        <a-input v-model="formData.phone" maxlength="11" />
      </a-form-item>
      <a-form-item label="姓名" field="name" :rules="[{ required: true, message: '必填项' }]">
        <a-input v-model="formData.name" />
      </a-form-item>
      <a-form-item label="邮箱" field="email" :rules="[{ required: true, message: '必填项' }]">
        <a-input v-model="formData.email" />
      </a-form-item>
      <a-form-item label="性别" field="sex" :rules="[{ required: true, message: '必填项' }]">
        <a-radio-group v-model="formData.sex">
          <a-radio value="M">男</a-radio>
          <a-radio value="W">女</a-radio>
        </a-radio-group>
      </a-form-item>
      <a-form-item label="是否启用" field="enabled" :rules="[{ required: true, message: '必填项' }]">
        <a-switch v-model="formData.enabled" checkedValue="Y" unCheckedValue="N" />
      </a-form-item>
      <a-form-item label="角色" field="roleIds" :rules="[{ required: true, message: '必填项' }]">
        <a-checkbox-group v-model="formData.roleIds">
          <a-checkbox :value="item.id" v-for="item in roleList" :key="item.id">{{item.roleName}}</a-checkbox>
        </a-checkbox-group>
      </a-form-item>
    </a-form>
  </CommonModal>
</template>

<script setup>
import {onMounted, ref} from "vue";
import {queryRole, submitUser} from "../../../api/core/user/user.js";
import CommonModal from "../../../core/component/CommonModal/CommonModal.vue";

const emit = defineEmits(['close'])
const props = defineProps({
  editData: { type: Object, default: {} }, // 编辑信息
});

const formRef = ref(null);

// 待编辑信息
const formData = ref({
  sex: 'M',
  enabled: 'Y',
  roleIds: []
});

// 角色信息
const roleList = ref([]);

onMounted(()=>{
  initRole();

  if (props.editData){
    formData.value = {...props.editData}
  }
})


function initRole(){
  queryRole().then(res=>{
    roleList.value = res.data;
  })
}

// 提交
function submit(){
  formRef.value.validate((err)=>{
    if (err){
      return;
    }

    // 组装数据
    const data = {...formData.value};
    submitUser(data).then(res=>{
      emit('close');
    })
  });
}
</script>
```
