

## 平台简介
一个基础管理系统脚手架，内置常规基础功能，适用于在此基础上，深度使用AI全栈开发，快速构建业务平台。整体功能架构十分精简。

## 内置功能
- 租户管理：支持多租户隔离管理，实现数据、配置及权限体系统一管控。
- 角色管理：维护租户角色体系，支持成员管理及菜单权限精细化分配。
- 用户管理：统一管理用户账号，支持角色授权及组织架构关联。
- 组织部门：支持企业组织架构维护，实现部门及人员统一管理。
- 岗位管理：维护岗位体系，支持岗位与人员关联管理。
- 企业管理：统一维护企业基础信息，支撑多组织业务管理。
- 通知管理：支持公告、消息统一发布，提供富文本、置顶及弹窗等能力。
- 字典配置：提供系统基础数据标准化维护能力。
- 文件管理：提供全平台文件统一存储及资源管理能力。
- 平台配置：支持系统级参数及配置项统一管理。
- 菜单管理：支持菜单资源维护及权限动态配置。
- LLM管理：支持大模型接入、配置及AI能力统一管理。
- 日志监控：记录用户操作行为，支持日志查询及审计追溯。
